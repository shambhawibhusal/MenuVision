# Plan: Firebase dishes Collection Delete Question

## Question to Answer
Can the user delete the `dishes` collection in Firebase? Will reviewed dishes be stored in `dishes` after deletion?

## Findings from Codebase

Based on exploring the codebase:

### Firebase Data Structure
- **`dishes` collection**: Root-level collection containing all dish documents
  - Each dish document has fields: id, name, place, price, category, cuisine, tags, etc.
  - Defined in `Frontend\src\hooks\useDishes.ts:15`

- **Reviews**: Stored as subcollection under each dish
  - Path: `dishes/{dishId}/reviews`
  - Defined in `Frontend\src\hooks\useDishReviews.ts:32`

### Answer

**No, you should NOT delete the `dishes` collection.**

1. If you delete the `dishes` collection:
   - ALL dish data will be permanently deleted
   - ALL reviews stored as subcollections (`dishes/{dishId}/reviews`) will ALSO be deleted since they are child data

2. Reviews are not stored separately - they are linked to each dish document. Deleting the parent `dishes` collection will cascade delete all reviews.

3. After deletion, there is no backup. You will lose:
   - All dish information (names, prices, categories, etc.)
   - All user reviews/ratings

## Recommended Action
Tell the user the answer directly - do NOT delete the dishes collection as it will permanently lose all reviewed dishes data.
