# Plan: Menu Dataset Collection in Firestore

## Goal
Create a centralized `menuDataset` collection in Firestore to store menu items. When users scan menus, check this dataset first - if dishes exist, use stored data; if not, add new entries.

## Current Flow
1. User scans menu → Backend extracts ALL dish data (name, price, description, ingredients, allergens, calories, image)
2. Frontend stores complete data in user's `history` in Firestore

## New Flow
1. User scans menu → Backend extracts ALL dish data
2. Frontend receives items with name + price only
3. For each item:
   - Query `menuDataset` by dish name (case-insensitive)
   - If exists: use stored data + scanned price
   - If not exists: add new entry to `menuDataset`, then use it
4. Store the final merged data in user's history

## Implementation Plan

### Step 1: Define Menu Dataset Schema
**Collection:** `menuDataset`
**Document ID:** Auto-generated (or hashed name)
**Fields:**
```typescript
{
  name: string;           // dish name (indexed for searching)
  description?: string;
  ingredients?: string[];
  allergens?: string[];
  calories?: number;
  prepTime?: string;
  imageUrl?: string;
  isVegan?: boolean;
  isVegetarian?: boolean;
  isGlutenFree?: boolean;
  origin?: string;
  category?: string;
  createdAt: timestamp;
  updatedAt: timestamp;
  scanCount: number;      // track popularity
}
```

### Step 2: Create Firestore Service for Menu Dataset
**File:** `Frontend/src/services/menuDataset.ts` (new)

Functions needed:
- `checkDishInDataset(dishName: string): Promise<MenuDatasetItem | null>`
- `addDishToDataset(dish: MenuDatasetItem): Promise<string>`
- `updateDishInDataset(dishId: string, data: Partial<MenuDatasetItem>): Promise<void>`
- `searchDishesByName(dishName: string): Promise<MenuDatasetItem[]>`

### Step 3: Modify Dashboard Scanning Logic
**File:** `Frontend/src/screens/Dashboard.tsx`

In `analyzeMenu` function (around line 605):
1. After receiving backend response, extract only name + price
2. For each item:
   - Call `checkDishInDataset(name)`
   - If found: merge dataset data with scanned price
   - If not found: add to dataset, then use the data
3. Store merged items in history

### Step 4: Update Firestore Rules
**File:** `firestore.rules`

Add read/write rules for `menuDataset` collection (authenticated users can read, write for new entries).

## Edge Cases to Handle
- Case-insensitive dish name matching (e.g., "Pizza" vs "pizza")
- Duplicate entries (check before adding)
- Price updates: always use scanned price, not stored price
- Offline/error handling for Firestore operations
