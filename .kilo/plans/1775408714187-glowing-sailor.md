# Plan: Switch from Pixabay to GPT Image 1.5 for Image Generation

## Goal
Replace Pixabay API with OpenAI GPT Image 1.5 for generating food images after menu scanning, and store generated images in Firebase Storage.

## Current Flow
1. User scans menu photo
2. Backend analyzes image with Gemini 2.5 Flash Lite
3. Backend fetches images from Pixabay for each dish
4. Returns menu items with images

## New Flow
1. User scans menu photo
2. Backend analyzes image with Gemini 2.5 Flash Lite
3. Backend generates images using GPT Image 1.5 for each dish
4. Backend uploads generated images to Firebase Storage
5. Returns menu items with permanent Firebase Storage URLs

## Implementation Steps

### 1. Install OpenAI Package
- Install `openai` package: `npm install openai` in Backend folder
- The backend already has `OPENAI_API_KEY` in `.env`

### 2. Configure Firebase Admin in Backend
- Add Firebase Admin config to `.env` (already has project details)
- Create a helper function to initialize Firebase Admin with Storage

### 3. Create Image Generation & Upload Function
```typescript
import { OpenAI } from "openai";
import { getStorage } from "firebase-admin/storage";

async function generateAndUploadImage(dishName: string): Promise<string | null> {
    const openai = new OpenAI({ apiKey: process.env.OPENAI_API_KEY });
    
    try {
        // Generate image using GPT Image 1.5
        const result = await openai.images.generate({
            model: "gpt-image-1.5",
            prompt: `Delicious ${dishName}, appetizing food photography, restaurant quality plated dish, 1024x1024`,
            size: "1024x1024",
            quality: "low",
            n: 1,
            response_format: "b64_json"  // Get base64 directly
        });
        
        const b64Image = result.data?.[0]?.b64_json;
        if (!b64Image) return null;
        
        // Upload to Firebase Storage
        const storage = getStorage();
        const fileName = `menu-images/${dishName.replace(/\s+/g, '-').toLowerCase()}-${Date.now()}.png`;
        const bucket = storage.bucket("menuvision-9acfc.appspot.com");
        const file = bucket.file(fileName);
        
        await file.save(Buffer.from(b64Image, "base64"), {
            contentType: "image/png"
        });
        
        // Make publicly accessible and return URL
        await file.makePublic();
        return `https://storage.googleapis.com/menuvision-9acfc.appspot.com/${fileName}`;
        
    } catch (err) {
        console.warn("[GPT Image] Generation/Upload failed:", err);
        return null;
    }
}
```
